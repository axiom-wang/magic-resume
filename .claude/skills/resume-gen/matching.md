## 1-page density contract

Default page budget (CN):

1. **Header** — name, contacts, city intent, 1-line target role (`basic.title` from JD).
2. **Education** — one block; awards as a short line, not a section dump.
3. **Internships** — up to **2**; each 2–3 HTML `<li>` bullets max.
4. **Projects** — **1–2**; each with plain-text `role` + 2–3 impact bullets in `description`.
5. **Skills** — 3–5 HTML lines max, JD-aligned only.
6. Optional **one** contest or org line if it is a clear differentiator (e.g. 京东神鲜杯全国冠军).

If still overflowing: cut org → cut second project → shorten internship bullets → drop interests. Never invent filler to reach a slot count.

When intake `emphasis` is set:

- `internships` — prefer keeping 2 internships; cut the weaker project first.
- `projects` — prefer keeping 2 projects; cut the weaker internship first.
- `balanced` — use the default cut order above.

Never drop an item named in intake `must_keep` unless the user later overrides.

## Multi-page override

When the user allows 1.5–2 pages: restore a third internship/project or one org block; keep the same profile priority order; still no fabrication.
